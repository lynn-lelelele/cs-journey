# Caesar · 2026.08.03

CS50 Problem Set 2：凯撒密码。

## 目标

输入一个数字 N 作为密钥，把每个字母往后挪 N 位，输出密文。非字母（空格、数字、标点）原样保留。

## 例子

```
$ ./caesar 3
plaintext:  Hello!
ciphertext: Khoor!
```

## 核心公式

字母 X 用密钥 k 加密：

```
密文 = (X - 'A' + k) % 26 + 'A'   → 大写公式
密文 = (X - 'a' + k) % 26 + 'a'   → 小写公式
```

拆解（以 z + 3 为例）：
- `X - 'a'` → 字母变成 0-25 的数字（z → 25）
- `+ k` → 加上密钥（25 + 3 = 28）
- `% 26` → 超出 z 绕回 a（28 % 26 = 2）
- `+ 'a'` → 数字变回字符（2 → 'c'）

顺序不能乱：先归零 → 挪位 → 绕回 → 还原。

## 关键知识点

1. **argc / argv[]**：命令行参数
   - `argc` = count = 参数个数（`./caesar 3` 是 2）
   - `argv[0]` = "./caesar"，`argv[1]` = "3"
   - c 记个数，v 记内容
2. **atoi()**：把字符串 `"3"` 变成数字 `3`（stdlib.h）
3. **ASCII 码**：字符本质是数字，'a'=97，'A'=65
4. **islower() / isupper()**：区分大小写
5. **原地修改**：`s[i] = 新值` 直接替换，不用新变量

## 学到了什么

- 字符就是数字，可以做加减乘除
- 循环移位用 `% 26` 处理边界
- 程序可以接收命令行参数，不用每次 scanf
