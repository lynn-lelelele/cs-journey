## 1. 损失函数基础

### 1.1 常见损失函数值域速查

| 损失 | 值域 | 说明 |
|---|---|---|
| 0-1 Loss | {0, 1} | 判对 0、判错 1，仅做评估 |
| 二分类交叉熵 (BCE) | (0, +∞) | 逻辑回归用，随机猜约 ln2 ≈ 0.693 |
| 多分类交叉熵 (CE) | (0, +∞) | 随机猜约 ln C |
| Hinge / Squared Hinge | [0, +∞) | SVM |
| Dice / IoU Loss | [0, 1] | 分割任务，有界 |
| MSE / MAE / Huber | [0, +∞) | 回归 |

### 1.2 0-1 Loss 细说

- 定义：L = 0（预测对）或 1（预测错），即指示函数 I[ŷ ≠ y]
- 二分类写法：间隔 z = y·f(x)，L = I[z ≤ 0]
- 值域只有 {0,1} 的原因：它是"对错计数器"，不关心置信度
- 平均 0-1 loss = 错误率，准确率 = 1 − 错误率
- **为什么不能用来训练**：不连续、非凸、梯度几乎处处为 0（没法梯度下降）、最小化错误率是 NP-hard、对边界样本惩罚不渐进
- **解决办法**：用光滑凸的替代损失（是 0-1 loss 的上界）：
  - Hinge: max(0, 1−z)（SVM）
  - Logistic: log2(1+e^(−z))（逻辑回归）
  - Exponential: e^(−z)（AdaBoost）
- 替代损失还会惩罚"判对但不够自信"的样本 → 逼出最大间隔 → 泛化更好

### 1.3 逻辑回归的损失/代价函数（吴恩达 C1W2）

单个样本的损失：

```
L(ŷ, y) = −[ y·log(ŷ) + (1−y)·log(1−ŷ) ]
```

整个训练集的代价（取平均）：

```
J(w, b) = (1/m) · Σᵢ L(ŷ⁽ⁱ⁾, y⁽ⁱ⁾)
```

- ŷ = σ(wᵀx + b)，σ(z) = 1/(1+e^(−z))，取值 0~1
- log 指自然对数 ln
- y = 1 时 L = −log(ŷ)；y = 0 时 L = −log(1−ŷ)
- 直觉：**真实类别被给出的概率越低，惩罚越狠**
- 为什么不用平方误差：套上 sigmoid 后 J 非凸，局部最优一堆；log 形式的 J 是凸的，只有全局最优

### 1.4 损失函数 vs 代价函数

| | 衡量范围 | 符号 |
|---|---|---|
| 损失函数 L | 一个样本 | L(ŷ, y) |
| 代价函数 J | 整个训练集平均 | J(w, b) |

### 1.5 代价函数的作用（4 个角色）

1. **成绩单**：用一个数量化"模型现在整体多差"
2. **优化目标**：训练 = 找 (w,b) 让 J(w,b) 最小
3. **指南针/梯度来源**：对参数求偏导得到梯度，告诉参数往哪调
4. **监控仪表**：训练时盯着 J 下降，评估时比较模型好坏

## 2. 梯度下降

### 2.1 目标与直觉

- 目标：找 w、b 使 J(w, b) 最小
- 直觉：站在山上 → 找最陡下坡方向 → 迈一步 → 重复到谷底

### 2.2 更新公式（核心）

```
重复直到收敛：
  w := w − α · ∂J/∂w
  b := b − α · ∂J/∂b
```

- := 表示"更新为"；先算右边再赋值
- α（alpha）= 学习率，控制步长
- 偏导数 = 坡度；**减号**是因为导数是"上坡方向"，下山要反着走

### 2.3 学习率的影响

```
α 太小  → 收敛极慢
α 合适  → 正常下坡
α 太大  → 来回震荡甚至发散
```

- 越接近谷底坡度越小，步长自动变小 → "先快后慢"
- 逻辑回归 J 是凸的 → 只有一个全局最优，梯度下降保证能找到
- 深层网络 J 非凸 → 只能找"足够好的局部最优"（后续课程重点）

## 3. 计算图与反向传播

### 3.1 计算图（Computation Graph）

把算 J 的过程拆成小步骤画成图，从左往右算 = 前向传播。
例子：J(a,b,c) = 3(a + bc)

```
u = b·c
v = a + u
J = 3v
```

意义：为反向传播提供"地图"，也是 TensorFlow / PyTorch 自动求导的底层思想。

### 3.2 计算图上的导数（反向传播直觉）

- **反向传播 = 从右往左，用链式法则把导数沿边相乘**
- 吴恩达记号：dvar = dJ/dvar（如 da、db、du、dv）

```
dJ/dv = 3
dJ/da = dJ/dv · dv/da = 3×1 = 3
dJ/du = 3
dJ/db = dJ/du · du/db = 3c
dJ/dc = dJ/du · du/dc = 3b
```

- 导数 = 敏感度：变量动一点点，J 动多少

### 3.3 逻辑回归单样本反向（重点，必会推导）

依赖链：L ← a ← z ← (w, b)

```
前向：
  z = w1·x1 + w2·x2 + b
  a = σ(z)
  L = −[ y·log a + (1−y)·log(1−a) ]

反向（链式法则）：
  dL/da = −y/a + (1−y)/(1−a)
  da/dz = a·(1−a)
  dz = dL/da × da/dz = a − y      ← 化简后的魔法公式
```

dz = a − y 的化简过程：

```
dz = [−y/a + (1−y)/(1−a)] × a(1−a)
   = −y(1−a) + (1−y)a
   = a − y
```

直觉：dz = 预测 − 标签。
- dz < 0：预测比标签小，z 偏低 → 参数往正方向调
- dz > 0：预测比标签大，z 偏高 → 参数往负方向调

## 4. m 个样本的梯度下降（Batch 梯度下降）

### 4.1 完整伪代码（一次迭代）

```
J = 0;  dw1 = 0;  dw2 = 0;  db = 0

for i = 1 to m:                        # 遍历所有样本（只累加，不更新）
    z[i]  = w1·x1[i] + w2·x2[i] + b
    a[i]  = σ(z[i])
    J     += −( y[i]·log(a[i]) + (1−y[i])·log(1−a[i]) )   # 累加损失（只监控）
    dz[i] = a[i] − y[i]
    dw1   += x1[i]·dz[i]               # 累加梯度
    dw2   += x2[i]·dz[i]
    db    += dz[i]

J = J/m;  dw1 = dw1/m;  dw2 = dw2/m;  db = db/m    # 取平均

w1 = w1 − α·dw1                                      # 最后统一更新
w2 = w2 − α·dw2
b  = b  − α·db
```

重复上面整段很多次直到收敛 = 完整训练。

### 4.2 关键纪律（必背）

1. **循环里只累加、绝不更新**；先算完所有偏导，再一起更新（同步更新）
2. **顺序：累加 → 平均 → 更新**，一步都不能乱
3. 除以 m：J 是平均损失 → 梯度也要平均，使梯度大小与样本数无关
4. J 只用于监控（看有没有下降），真正驱动更新的是 dw1、dw2、db
5. 这整段 = 梯度下降**一步**；外面还要套"重复直到收敛"
6. 两个隐式循环（m 个样本 × 特征数）→ 慢 → 下一节用**向量化**解决

### 4.3 责任分摊：为什么 dw = x·dz（三行反向的理解）

```
z = w1·x1 + w2·x2 + b

w1 动 1 单位 → z 动 x1 单位（影响系数 x1）
w2 动 1 单位 → z 动 x2 单位（影响系数 x2）
b  动 1 单位 → z 动 1  单位（影响系数 1）

误差按影响系数分配：
  dw1 = x1·dz
  dw2 = x2·dz
  db  = dz
```

- 影响系数大的参数对 z 影响大 → 分到更多误差（梯度）
- db 不乘 x，是因为 b 的系数是隐含的 1
- dw 是"梯度/敏感度"，实际改动 = −α·dw

### 4.4 手算例子（m=2，2 个特征）

数据：样本1 (x1=1, x2=2, y=1)；样本2 (x1=2, x2=1, y=0)
初始 w1=w2=b=0，α=0.5

```
i=1: z=0, a=0.5, dz=0.5−1=−0.5, dw1=−0.5, dw2=−1.0, db=−0.5, J累加=0.693
i=2: z=0, a=0.5, dz=0.5−0=0.5, dw1=+1.0→0.5, dw2=+0.5→−0.5, db=0, J累加=1.386

平均：J=0.693, dw1=0.25, dw2=−0.25, db=0

更新：w1 = −0.125, w2 = 0.125, b = 0
```

1. **向量化（C1W2 后半）**：把双 for 循环换成 numpy 一行：dw = np.dot(X, dz) / m
