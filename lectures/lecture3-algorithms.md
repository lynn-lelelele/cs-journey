## 一、查找算法(Search)

### 线性查找(Linear Search)——顺序遍历

从头到尾逐一遍历数组元素，直到找到目标。

```
最坏情况：n 个元素需比较 n 次 → 时间复杂度 O(n)
```

### 二分查找(Binary Search)——对半排除

**前提：数组必须有序。** 每次取中间元素与目标比较，根据大小关系舍弃一半区间。

```
每次排除一半 → 时间复杂度 O(log n)
```

> 比喻：查字典时先翻中间页，根据字母范围决定往前还是往后翻，而不是从第一页翻起。

## 二、排序算法(Sorting)

| 算法 | 思路 | 时间复杂度 |
|------|------|-----------|
| 冒泡排序(Bubble Sort) | 相邻元素两两比较，较大者后移 | O(n²) |
| 选择排序(Selection Sort) | 每轮选出最小值放到前端 | O(n²) |
| 归并排序(Merge Sort) | 分治：拆半排序后合并 | O(n log n) |

> 冒泡排序的"冒泡"比喻：较大的元素像气泡一样逐步上浮到末尾。

## 三、时间复杂度分析(Big-O 表示法)

衡量算法效率时，关注**最坏情况**下，随着输入规模 n 增大，操作次数的增长量级：

```
O(n²)     n=100 → 10000 步      ← 慢
O(n log n) n=100 → 约 700 步
O(n)      n=100 → 100 步
O(log n)  n=100 → 7 步
O(1)      永远 1 步             ← 最快
```

要点：
- Big-O 描述**渐进复杂度**，忽略常数项与低阶项。
- 空间复杂度同理，衡量额外内存的消耗。

## 四、递归(Recursion)

函数调用自身的编程技巧。

```c
int factorial(int n)
{
    if (n == 1) return 1;        // 递归基（终止条件）
    return n * factorial(n - 1); // 递归调用：规模减一
}
```

两个必要要素：
1. **递归基(Base Case)**：终止递归的条件。
2. **规模缩小(Reduction)**：每次调用向基靠近。

> 递归依赖**调用栈(Call Stack)**：每次调用压栈，返回时逐层出栈。

## 六、字符串比较：strcmp

```c
strcmp(a, b)
// 相等 → 返回 0
// a > b → 返回正数
// a < b → 返回负数
```

**注意：字符串不能直接用 `==` 比较。** `==` 比较的是内存地址而非内容，必须用 `strcmp` 逐字符比较。
