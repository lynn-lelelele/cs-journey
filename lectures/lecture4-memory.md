# CS50 Lecture 4 · 内存(Memory)与指针(Pointer) · 课堂笔记

> 适用读者：掌握数组、字符串与函数的初学者。
> 学习目标：理解内存地址、指针、字符串的底层表示，以及动态内存分配(malloc/free)。

> 本课核心：**指针（pointer）**——保存内存地址的变量。

> 比喻：内存是一排排有编号的储物柜；变量是柜中物品；地址是柜子编号；指针是记着"东西在几号柜"的纸条。

---

## 一、变量与内存地址(Address)

每个变量在内存中都有唯一地址：

```c
int n = 42;
printf("%p\n", &n);   // 打印 n 的地址，如 0x7ffe12ab34cd（十六进制）
```

- `&n`：取地址运算符，得到 n 的内存地址。
- 地址通常以十六进制表示（如 `0x7ffe...`）。

---

## 二、指针(Pointer)与解引用

```c
int n = 42;
int *p = &n;     // p 是指针，保存 n 的地址
printf("%d\n", *p);  // 解引用：顺着地址取出值 = 42
```

| 写法 | 含义 |
|------|------|
| `int *p` | 声明指针变量，类型为"指向 int 的指针" |
| `p = &n` | 将 n 的地址存入 p |
| `*p` | 解引用：访问指针指向的内存 |

**通过指针修改目标值：**

```c
int n = 10;
int *p = &n;
*p = 99;          // 通过指针向 n 的地址写入 99
printf("%d\n", n); // 99
```

**多个指针可指向同一地址：**

```c
int n = 5;
int *p = &n;
int *q = &n;
*q = 100;
printf("%d\n", *p); // 100，p 与 q 观察同一地址
```

## 三、字符串的本质：字符指针

```c
string s = "hi";   // string 本质是 char *
```

- 字符串变量保存的是**首字符的地址**，而非字符本身。
- 字符串以空字符 `\0` 结尾。

**为什么字符串不能直接 `==` 比较：**

```c
string a = "hi";
string b = "hi";
a == b          // 比较的是地址，通常不相等
strcmp(a, b) == 0  // 比较内容，正确做法
```

**字符数组 vs 字符指针：**

```c
char s[] = "hi";   // 分配实际存储空间（3 个字符）
char *s = "hi";    // 仅保存首字符地址
```

---

## 四、复制字符串的陷阱

```c
string s = "hi";
string t = s;      // 仅复制指针，t 与 s 指向同一内存
t[0] = 'H';        // s 也会变成 "Hi"
```

正确做法：动态分配新内存并逐字符复制。

```c
string t = malloc(strlen(s) + 1);   // +1 为 '\0' 预留
for (int i = 0; i <= strlen(s); i++)
    t[i] = s[i];
```

| 写法 | 结果 |
|------|------|
| `string t = s;` | 仅复制指针，共享内存 |
| `malloc` + 逐字符复制 | 复制内容，独立内存 |

---

## 五、动态内存分配：malloc 与 free

```c
#include <stdlib.h>

int *arr = malloc(10 * sizeof(int));  // 申请 10 个 int 的空间
arr[0] = 3;
arr[1] = 7;

free(arr);   // 释放内存；不释放则造成内存泄漏
```

- `malloc`：申请堆内存，返回首地址。
- `free`：释放内存，归还系统。
- `sizeof(int)`：获取类型字节数，避免写死。
- malloc 失败返回 `NULL`，使用前应检查。

## 术语表

| 术语 | 含义 |
|---|---|
| 内存地址 | 变量在内存中的唯一编号 |
| 指针 | 保存地址的变量 |
| 解引用 | 通过地址访问目标内存 |
| 十六进制 | 基数为 16 的计数法（地址常用） |
| 字符串字面量 | 代码中直接书写的字符串常量 |
| 动态内存分配 | 运行时向系统申请内存 |
| 内存泄漏 | 申请后未释放导致的内存浪费 |
| NULL | 空指针，表示"不指向任何地址" |

## 一句话总结

**内存是柜子，指针是记地址的纸条：`&` 问地址，`*` 开柜子，malloc 借、free 还。**
