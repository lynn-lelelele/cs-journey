## 生活比喻

- 内存 = 一排排有编号的储物柜
- 变量 = 柜子里放的东西
- 地址 = 柜子的编号
- 指针 = 记着"东西在几号柜"的小纸条

---

## 第 1 课：变量住在哪？（& 取地址）

```c
int n = 42;
printf("%p\n", &n); // 打印 n 在内存里的地址，比如 0x7ffe...（一长串数字）
```

- `&n` = 取 n 的地址 = "n 住在几号柜"
- 地址长这样：`0x7ffe12ab34cd`（十六进制）
- 每个变量都有自己的地址，互不相同（一个柜子只能放一个东西）

## 第 2 课：指针（*）[重点] 本课最重要

```c
int n = 42;
int *p = &n; // p 是个指针，存着 n 的地址
printf("%d\n", *p); // *p = 顺着地址找到的东西 = 42
```

| 写法 | 意思 |
|------|------|
| `int *p` | 声明：p 是指针，存 int 的地址 |
| `p = &n` | 把 n 的地址存进 p |
| `*p` | 解引用：打开柜子，拿出里面的值 |

口诀：`&` = 拿地址，`*` = 解引用。

### 例子：用指针改柜子里的东西

```c
int n = 10;
int *p = &n;
*p = 99; // 通过纸条，往 n 的柜子里塞 99
printf("%d\n", n); // 99（n 被改了！）
```

### 例子：两张纸条指向同一柜子

```c
int n = 5;
int *p = &n;
int *q = &n;
*q = 100;
printf("%d\n", *p); // 100（p q 看的是同一个柜子）
```

## 第 3 课：字符串 = 指针

```c
string s = "hi"; // 其实 string 就是 char *
```

s 存的不是字母，而是**第一个字母 h 的地址**。字符串 = 一串字符 + 末尾 `\0`。

### 为什么字符串不能直接 ==

a 和 b 是两张纸条，即使内容一样，地址也可能不同：
```c
string a = "hi"; string b = "hi";
a == b // ❌ 比地址，多半不相等
strcmp(a, b) == 0 // [完成] 比内容
```

### 字符数组 vs 指针

```c
char s[] = "hi"; // 真的开了 3 个柜子
char *s = "hi"; // 只记着开头地址
```

## 第 4 课：复制字符串的坑

```c
string s = "hi";
string t = s; // ❌ 只复制了纸条！t 和 s 指向同一处
t[0] = 'H'; // s 也变成 "Hi" 了！
```

要真的复制，用 malloc 开新柜子：
```c
string t = malloc(strlen(s) + 1); // +1 给 \0
for (int i = 0; i <= strlen(s); i++)
 t[i] = s[i];
```

| 写法 | 结果 |
|------|------|
| `string t = s;` | ❌ 只复制纸条，俩指向同一处 |
| `malloc` + 循环复制 | [完成] 真的开了新柜子 |

## 第 5 课：malloc / free

```c
#include <stdlib.h>

int *arr = malloc(10 * sizeof(int)); // 申请 10 个空柜子
arr[0] = 3; // 放什么是你自己定的（例子而已）
arr[1] = 7;

free(arr); // 用完必须还！不还 = 内存泄漏
```

- malloc = 借柜子（申请内存）
- free = 还柜子（释放）
- `sizeof(int)` 算一个 int 多大，别写死数字
- 申请失败返回 `NULL`，要先检查再用

## 一句话总结

**内存是一排柜子，指针是记地址的纸条，`&` 问地址，`*` 开柜子，malloc 借、free 还。**
