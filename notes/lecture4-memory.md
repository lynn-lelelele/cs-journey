## 生活比喻

- 内存 = 一排排有编号的储物柜
- 变量 = 柜子里放的东西
- 地址 = 柜子的编号
- 指针 = 记着"东西在几号柜"的小纸条

---

## 第 1 课：变量住在哪？（& 取地址）

```c
int n = 42;
printf("%p\n", &n);   // 打印 n 在内存里的地址，比如 0x7ffe...（一长串数字）
```

- `&n` = 取 n 的地址 = "n 住在几号柜"
- 地址长这样：`0x7ffe12ab34cd`（十六进制）
- 每个变量都有自己的地址，互不相同

```c
int a = 1;
int b = 2;
printf("%p\n", &a);   // 输出一串地址
printf("%p\n", &b);   // 另一串地址，和 a 不同
```

## 第 2 课：指针（*）

```c
int n = 42;
int *p = &n;      // p 是个指针，存着 n 的地址
printf("%d\n", *p);   // *p = 顺着地址找到的东西 = 42
```

- `int *p` = 声明"p 是个存 int 地址的指针"
- `p = &n` = 把 n 的地址放进 p
- `*p` = 解引用 = 打开柜子拿东西

## 第 3 课：字符串 = 指针

```c
string s = "hi";    // 其实 string 就是 char *
```

s 存的不是字母，而是**第一个字母 h 的地址**。字符串 = 一串字符 + 末尾 `\0`。

## 第 4 课：比较字符串的坑

```c
string a = "hi";
string b = "hi";
if (a == b) ...      // ❌ 错！比的是地址（两个地址不同）
if (strcmp(a, b) == 0) ...  // ✅ 对！比内容
```

## 第 5 课：malloc / free

```c
int *arr = malloc(10 * sizeof(int));  // 申请能放 10 个 int 的内存
// 用完要还！
free(arr);
```

- malloc = 申请内存（向系统借柜子）
- free = 释放（还柜子）
- 不 free = 内存泄漏（借了不还）

## 一句话总结

**指针 = 存地址的变量。& 拿地址，* 解引用。**
