# Readability · 2026.08.02

CS50 Problem Set 2：阅读难度等级。

## 目标

输入一段英文，输出 Coleman-Liau 指数（对应美国几年级的阅读水平）。

## 公式

```
index = 0.0588 * L - 0.296 * S - 15.8
```

- **L** = 每 100 个单词的平均字母数
- **S** = 每 100 个单词的平均句子数
- 结果四舍五入，碰到边界情况输出 "Before Grade 1" 或 "Grade 16+"

## 关键问题

1. 怎么判断一个字符是 **字母**？
2. 怎么判断是一个 **单词** 的结束？
3. 怎么判断是一个 **句子** 的结束？
4. `float` 和 `int` 怎么转换？四舍五入怎么写？

## 学到了什么

### 1. 字符串在 C 里就是字符数组

- `string s` 本质上就是 `char s[]`
- `s[i]` 可以拿到第 i 个字符
- `strlen(s)` 拿到字符串长度
- 字符串末尾有一个隐藏的 `'\0'`（空字符），标志字符串结束

### 2. `isalpha()` — 判断字母

- 来自 `<ctype.h>`
- `isalpha('a')` → true，`isalpha(' ')` → false
- 大小写都认，不用自己写 `>= 'a' && <= 'z'`

### 3. 单词计数技巧

- 初始化 `words = 1`（因为最后一个单词后面没有空格）
- 遇到空格就 `words++`
- 本质：空格数 + 1 = 单词数

### 4. 句子计数

- 遇到 `.` `!` `?` 就 `sentences++`
- 用 `||`（或）连起来判断

### 5. int → float 转换（避免整除截断）

- `int / int` 会截断小数，比如 `5 / 2 = 2` ❌
- `(float) letters / words` 先转成浮点再除，得到 `2.5` ✅
- 这叫**类型转换（type casting）**

### 6. `round()` 四舍五入

- 来自 `<math.h>`
- `round(2.3)` → `2.0`，`round(2.6)` → `3.0`
- 结果赋给 `int`，得到整数等级

### 7. 编译和运行流程

- `make readability` → 编译（cs50 环境）
- `./readability` → 运行
- VS Code 终端按 `Ctrl+~` 打开

## 踩了什么坑

| 坑 | 原因 | 解决 |
|----|------|------|
| `gcc` 在本地找不到 | Windows 没装 C 编译器 | 用 cs50.dev 在线环境 |
| 变量名不一致 | 定义 `int letter`，用的时候写 `letters` | 统一命名，复制粘贴检查 |
| `letters++` 忘了分号 | C 每句结尾都要 `;` | 看编译器报错行号 |
| VS Code 没保存 | 改了代码但没 Ctrl+S | 养成肌肉记忆：改完就保存 |
| 不小心删档 | 误操作 | Ctrl+Z 撤回 / 重新贴 |
| 终端直接粘贴英文当成命令 | 没先输入 `./readability` | 先运行程序，等 `Text:` 出来再贴 |

## 下次改进

- 写完变量先检查有没有拼写不一致的地方
- 每个 `if` 的大括号对齐，避免漏 `}` 或 `;`
